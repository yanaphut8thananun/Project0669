Google Sheets หลัก

ข้อมูลทั้งหมดถูกซิงโครไนซ์สดผ่าน Google Sheet แผ่นงานจริงของวิทยาลัยเทคนิคอุทัยธานี

เปิดแผ่นงานจริง (Google Sheets)

วิธีการอัปเดตข้อมูล:

  1. เข้าไปแก้ไขข้อมูลโครงการที่ต้องการใน Google Sheet ด้านบน
  2. เมื่อมีการแก้ไขใน Google Sheet แล้ว ข้อมูลจะถูกจัดเก็บลงเซิร์ฟเวอร์ของ Google ทันที
  3. ระบบ Dashboard นี้จะทำการดึงข้อมูลล่าสุดมาประมวลผลใหม่โดยอัตโนมัติทุกครั้งที่มีผู้เปิดหน้าเว็บนี้ หรือสามารถกดปุ่ม "ดึงข้อมูลล่าสุด" ที่มุมบนขวาเพื่อบังคับรีเฟรชข้อมูลโดยไม่ต้องกด F5

การเผยแพร่ผ่าน GitHub Pages

เว็บไซต์แดชบอร์ดนี้ถูกเตรียมไฟล์โครงสร้างสำหรับการเผยแพร่ฟรีผ่านบริการ GitHub Pages เรียบร้อยแล้ว (ไม่จำเป็นต้องมีเวอร์เชียลเซิร์ฟเวอร์เพิ่มเติม)

ขั้นตอนการอัปโหลดขึ้น GitHub:
  • สร้าง Repository ใหม่บนบัญชี GitHub ของคุณ
  • เปิด Git Bash / Terminal ในโฟลเดอร์นี้แล้วรันคำสั่ง Git เพื่ออัปโหลดไฟล์
  • ไปที่หน้าเมนู Settings > Pages ใน Repository บน GitHub
  • เลือก Branch เป็น main หรือ master แล้วกด Save
  • ระบบจะเผยแพร่เว็บออกมาในรูปแบบลิงก์ https://[ชื่อคุณ].github.io/[ชื่อบอร์ด]/ ทันที

รายละเอียดคำสั่งฉบับเต็มถูกเขียนบันทึกไว้ในไฟล์ README.md ภายในโครงการแล้ว
