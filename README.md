# Executive Dashboard - ระบบรายงานติดตามโครงการ วิทยาลัยเทคนิคอุทัยธานี

ระบบเว็บไซต์รายงานติดตามสถานะและวิเคราะห์งบประมาณโครงการ สำหรับผู้บริหาร วิทยาลัยเทคนิคอุทัยธานี พัฒนาขึ้นในรูปแบบ Single Page Application (Static Web App) ที่ดึงข้อมูลโดยตรงแบบสด ๆ (Live Connection) จาก Google Sheets

## ลิงก์แหล่งข้อมูลหลัก
* **Google Sheet**: [แผ่นงานจัดการโครงการ วิทยาลัยเทคนิคอุทัยธานี](https://docs.google.com/spreadsheets/d/1HavaRP_aBeWX3hrfTGa2R6ky31N5-yGkUhgSzEfcpfQ/edit?usp=sharing)

## ฟังก์ชันการทำงานของระบบ
1. **ซิงโครไนซ์ข้อมูลแบบ Real-time**: เมื่อมีคนเข้าหน้า Dashboard ระบบจะทำ HTTP Request ไปดึงข้อมูล CSV ล่าสุดของ Google Sheet มาคำนวณและอัปเดตสถิติต่าง ๆ ในทันที
2. **ระบบการเงินติดตามโครงการ**: คำนวณงบประมาณรวม, งบประมาณที่ใช้จ่ายจริง, งบประมาณคงเหลือสุทธิ และเปอร์เซ็นต์เบิกจ่าย ทั้งภาพรวมวิทยาลัยและเป็นรายโครงการ
3. **แผนภูมิโต้ตอบ (Interactive Charts)**:
   - แผนภูมิวงกลมแสดงสัดส่วนสถานะโครงการ (ดำเนินการแล้ว, อยู่ระหว่างดำเนินการ, ยังไม่ดำเนินการ)
   - แผนภูมิแท่งเปรียบเทียบงบประมาณที่ตั้งไว้และเงินที่จ่ายจริงของแต่ละโครงการเพื่อตรวจสอบประสิทธิภาพการเงิน
4. **ตารางรายละเอียดวิเคราะห์**: ผู้บริหารสามารถคลิกชื่อโครงการเพื่อเปิดหน้าต่างดูข้อมูลสรุปโดยละเอียดได้ มีแถบค้นหาและตัวกรองกลุ่มงานเพื่อลดเวลาเข้าถึงข้อมูล
5. **โหมดถนอมสายตา (Light/Dark Mode)**: บันทึกธีมที่เลือกไว้ให้โดยอัตโนมัติ

## ขั้นตอนการเตรียมข้อมูลและการทำงานของ Google Sheet
* ข้อมูลจะถูกบันทึกและแก้ไขบน Google Sheets เท่านั้น แผงควบคุมบนหน้าเว็บบอร์ดจะทำหน้าที่แสดงผลอย่างเดียว (Read-only) เพื่อความปลอดภัยของข้อมูล
* หน้าเว็บบอร์ดมีปุ่ม **"ดึงข้อมูลล่าสุด (Sync Data)"** สำหรับบังคับรีเฟรชข้อมูลล่าสุดโดยไม่ต้องกด F5

## ขั้นตอนการอัปโหลดขึ้น GitHub เพื่อเผยแพร่ระบบ (GitHub Pages Deployment Guide)

คุณสามารถนำหน้าเว็บไซต์แดชบอร์ดนี้ขึ้นไปแสดงผลออนไลน์บนเครือข่ายอินเทอร์เน็ตได้ฟรีผ่านบริการ **GitHub Pages** โดยทำตามขั้นตอนดังต่อไปนี้:

### 1. สมัครใช้งานและสร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub.com](https://github.com/) และเข้าสู่ระบบ (หรือสมัครสมาชิก)
2. กดปุ่ม **New** (หรือคลิกที่เครื่องหมาย `+` มุมบนขวา เลือก **New repository**)
3. ตั้งชื่อ Repository (เช่น `executive-dashboard`)
4. เลือกการเข้าถึงเป็น **Public**
5. **ห้าม** เช็กเลือก "Add a README file" หรืออื่น ๆ เพื่อหลีกเลี่ยงความขัดแย้งในการ Push ข้อมูลตัวแรก
6. กดปุ่ม **Create repository**

### 2. รันคำสั่ง Git ในคอมพิวเตอร์ของคุณ
เปิด Git Bash (หรือ Terminal ในโฟลเดอร์โครงการนี้) แล้วรันคำสั่งต่อไปนี้ทีละคำสั่ง:

```bash
# 1. เริ่มใช้งาน Git ในโฟลเดอร์นี้
git init

# 2. เพิ่มไฟล์ทั้งหมดเข้าไปในระบบติดตามของ Git
git add .

# 3. ยืนยันการบันทึกเวอร์ชันแรก
git commit -m "Initialize Technical College Executive Dashboard"

# 4. ตั้งชื่อกิ่งหลักเป็น main
git branch -M main

# 5. เชื่อมต่อโฟลเดอร์นี้กับบัญชี GitHub ของคุณ (นำ URL จากหน้าบราวเซอร์ GitHub ของคุณมาเปลี่ยนแทน URL ด้านล่าง)
git remote add origin https://github.com/[ชื่อผู้ใช้ของคุณ]/[ชื่อ-repo-ของคุณ].git

# 6. อัปโหลดโค้ดทั้งหมดขึ้นไปยัง GitHub
git push -u origin main
```

### 3. ตั้งค่าเปิดใช้งาน GitHub Pages เพื่อเผยแพร่เว็บ
หลังจากสั่ง Push โค้ดเสร็จเรียบร้อยแล้ว ให้ทำดังนี้:
1. เข้าไปที่หน้าโครงการของคุณบนเว็บ GitHub
2. คลิกเลือกเมนู **Settings** (รูปฟันเฟืองด้านบน)
3. ที่แถบเมนูด้านซ้าย มองหาและคลิกเลือกหัวข้อ **Pages**
4. ในส่วนของ **Build and deployment** ให้ตั้งค่าดังนี้:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เปลี่ยนจาก `None` เป็น `main` (และเลือกโฟลเดอร์หลักเป็น `/ (root)`)
5. กดปุ่ม **Save**
6. รอประมาณ 1-2 นาที ให้รีเฟรชหน้านั้น GitHub Pages จะสร้างลิงก์เว็บไซต์สำหรับเข้าชม Dashboard ขึ้นมาให้ทันที เช่น `https://[ชื่อผู้ใช้ของคุณ].github.io/[ชื่อ-repo-ของคุณ]/`
